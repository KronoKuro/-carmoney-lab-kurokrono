## ask

Агент только прочитал Makefile, docker-compose.yml и AppFactory.php, разобрался в теме
и выдал готовый текст раздела в чат. Файлы не тронул — прямо написал, что в режиме ask
править не может, и попросил переключиться на code. Ничего не спрашивал и не предлагал
внести правку сам.

## code

Тот же промпт — агент сразу предложил конкретное действие: «добавлю раздел в README
после таблицы команд», затем **сам внёс правку** в `README.md` и отчитался, что именно
и куда добавил. Разрешения явно не спрашивал, потому что промпт содержал прямое указание
«добавь раздел» — в режиме code это воспринимается как команда на правку.

## Какой агент возьму для разбора кода

Для разбора чужого кода без риска что-то случайно сломать — **ask**.
Для задач, где нужно сразу получить правку в файле, — **code**.
